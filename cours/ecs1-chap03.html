ECS (1re année) — Chapitre 03. Divisibilité dans \mathbb{K}[X], racines, multiplicité, factorisation.

Ce chapitre a été réalisé conformément au programme marocain de mathématiques de la filière ECS.

Dans tout ce chapitre, \mathbb{K} désigne \mathbb{R} ou \mathbb{C}.

1 L’anneau \mathbb{K}[X]

1.1 Définition

Définition 1.1 — (Polynôme)

Un polynôme à coefficients dans \mathbb{K} est une expression de la forme : P(X) = a_0 + a_1 X + a_2 X^2 + \cdots + a_n X^n = \sum_{k=0}^n a_k X^k où a_0, a_1, \ldots, a_n \in \mathbb{K}. On note \mathbb{K}[X] l’ensemble des polynômes à coefficients dans \mathbb{K}.

Définition 1.2 — (Degré)

Si P(X) = a_n X^n + \cdots + a_0 avec a_n \neq 0, le degré de P est n, noté \deg(P) = n. Le coefficient a_n est appelé coefficient dominant.

Proposition 1.1 — (Opérations)

Pour tous polynômes P, Q \in \mathbb{K}[X] :

  1. \deg(P + Q) \leq \max(\deg P, \deg Q).
  2. \deg(PQ) = \deg P + \deg Q (si P, Q \neq 0).
  3. \mathbb{K}[X] est un anneau intègre (pas de diviseurs de zéro).

1.2 Division euclidienne

Théorème 1.1 — (Division euclidienne)

Pour tous A, B \in \mathbb{K}[X] avec B \neq 0, il existe un unique couple (Q, R) \in \mathbb{K}[X]^2 tel que : A = BQ + R \qquad \text{avec} \qquad \deg R < \deg B

Q est le quotient et R le reste de la division de A par B.

Définition 1.3 — (Divisibilité)

On dit que B divise A, noté B \mid A, si le reste de la division de A par B est nul, c’est-à-dire s’il existe Q \in \mathbb{K}[X] tel que A = BQ.

Exemple 1.1

Diviser A = X^3 + 2X^2 - X + 3 par B = X - 1.

On trouve A = (X-1)(X^2 + 3X + 2) + 5. Le quotient est Q = X^2 + 3X + 2 et le reste est R = 5.

2 Racines et multiplicité

2.1 Racines

Définition 2.1 — (Racine)

\alpha \in \mathbb{K} est une racine de P \in \mathbb{K}[X] si P(\alpha) = 0.

Théorème 2.1 — (Lien avec la divisibilité)

\alpha est racine de P si et seulement si (X - \alpha) \mid P(X).

Preuve. Par division euclidienne : P(X) = (X-\alpha)Q(X) + R avec \deg R < 1, donc R est une constante. En évaluant en \alpha : P(\alpha) = 0 \cdot Q(\alpha) + R = R. Donc R = 0 si et seulement si P(\alpha) = 0.

2.2 Multiplicité

Définition 2.2 — (Multiplicité)

\alpha est racine de P de multiplicité m \geq 1 si (X-\alpha)^m \mid P(X) et (X-\alpha)^{m+1} \nmid P(X).

Autrement dit, P(X) = (X-\alpha)^m Q(X) avec Q(\alpha) \neq 0.

Proposition 2.1 — (Caractérisation par la dérivée)

\alpha est racine de multiplicité m de P si et seulement si : P(\alpha) = P'(\alpha) = \cdots = P^{(m-1)}(\alpha) = 0 \quad \text{et} \quad P^{(m)}(\alpha) \neq 0

Exemple 2.1

P(X) = X^3 - 3X^2 + 3X - 1 = (X-1)^3.

1 est racine de multiplicité 3 car P(1) = P'(1) = P''(1) = 0 et P'''(1) = 6 \neq 0.

2.3 Dérivée formelle

Définition 2.3 — (Dérivée formelle)

Si P(X) = \sum_{k=0}^n a_k X^k, la dérivée formelle de P est : P'(X) = \sum_{k=1}^n k a_k X^{k-1}

Proposition 2.2

(P + Q)' = P' + Q', (\lambda P)' = \lambda P' et (PQ)' = P'Q + PQ'.

3 Factorisation

3.1 Théorème de d’Alembert-Gauss

Théorème 3.1 — (Théorème de d’Alembert-Gauss)

Tout polynôme non constant P \in \mathbb{C}[X] admet au moins une racine dans \mathbb{C}.

En particulier, tout polynôme P \in \mathbb{C}[X] de degré n \geq 1 se factorise complètement dans \mathbb{C}[X] : P(X) = a_n \prod_{k=1}^n (X - \alpha_k) où \alpha_1, \ldots, \alpha_n sont les racines de P (comptées avec multiplicité).

3.2 Factorisation dans \mathbb{R}[X]

Théorème 3.2 — (Irréductibles de \boldsymbol{\mathbb{R}[X]})

Les polynômes irréductibles de \mathbb{R}[X] sont :

  • Les polynômes de degré 1 : aX + b avec a \neq 0.
  • Les polynômes de degré 2 sans racine réelle : aX^2 + bX + c avec \Delta = b^2 - 4ac < 0.

Proposition 3.1 — (Factorisation dans \boldsymbol{\mathbb{R}[X]})

Tout polynôme P \in \mathbb{R}[X] de degré n \geq 1 se factorise dans \mathbb{R}[X] en produit de polynômes irréductibles : P(X) = a_n \prod_{i} (X - \alpha_i) \prod_{j} (X^2 + p_j X + q_j) où les \alpha_i sont les racines réelles et les X^2 + p_j X + q_j sont les facteurs irréductibles de degré 2 (avec \Delta_j < 0).

Exemple 3.1

Factoriser P(X) = X^4 - 1 dans \mathbb{R}[X] et \mathbb{C}[X].

Dans \mathbb{C}[X] : X^4 - 1 = (X-1)(X+1)(X-i)(X+i).

Dans \mathbb{R}[X] : X^4 - 1 = (X-1)(X+1)(X^2+1).

Exemple 3.2

Factoriser Q(X) = X^3 - 1.

Dans \mathbb{C}[X] : X^3 - 1 = (X-1)(X-e^{2i\pi/3})(X-e^{-2i\pi/3}).

Dans \mathbb{R}[X] : X^3 - 1 = (X-1)(X^2+X+1).

4 Exercices

Exercice 4.1

Effectuer la division euclidienne de A = X^4 + 3X^3 - X + 2 par B = X^2 + X - 1.

Exercice 4.2

Déterminer les racines et leur multiplicité de :

  1. P(X) = X^3 - 6X^2 + 11X - 6
  2. Q(X) = X^4 - 2X^3 + X^2

Exercice 4.3

Factoriser dans \mathbb{R}[X] et \mathbb{C}[X] :

  1. X^4 + 1
  2. X^6 - 1
  3. X^3 + 2X^2 + 2X + 1

Exercice 4.4

Soit P(X) = X^n - 1. Déterminer les racines de P dans \mathbb{C}.

Exercice 4.5

Montrer que si P \in \mathbb{R}[X] admet une racine complexe non réelle \alpha, alors \bar{\alpha} est aussi racine de P.

Exercice 4.6

Soit P(X) = X^3 + aX^2 + bX + c avec a, b, c \in \mathbb{R}. On suppose que P admet trois racines réelles r_1, r_2, r_3. Exprimer a, b, c en fonction de r_1, r_2, r_3.

Exercice 4.7

Montrer que le polynôme P(X) = X^2 + X + 1 est irréductible dans \mathbb{R}[X] mais pas dans \mathbb{C}[X].

Exercice 4.8

Soit P \in \mathbb{R}[X] de degré impair. Montrer que P admet au moins une racine réelle.
