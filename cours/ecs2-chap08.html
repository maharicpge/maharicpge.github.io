ECS (2e année) — Chapitre 08. Lois conjointes, marginales, conditionnelles, covariance, corrélation linéaire.

Ce chapitre a été réalisé conformément au programme marocain de mathématiques de la filière ECS.

Dans tout ce chapitre, (X, Y) désigne un couple de variables aléatoires.

1 Loi conjointe

Définition 1.1 — (Loi conjointe)

La loi conjointe de (X, Y) est la donnée des P(X = x, Y = y) pour (x, y) \in X(\Omega) \times Y(\Omega), avec : \sum_{x} \sum_{y} P(X = x, Y = y) = 1

2 Lois marginales

Définition 2.1 — (Lois marginales)

Les lois marginales de X et Y sont : P(X = x) = \sum_y P(X = x, Y = y), \quad P(Y = y) = \sum_x P(X = x, Y = y)

Exemple 2.1

Soit (X, Y) de loi conjointe :

X \setminus Y 0 1
0 1/4 1/4
1 1/4 1/4

Lois marginales : P(X = 0) = P(X = 1) = 1/2, idem pour Y.

3 Lois conditionnelles

Définition 3.1 — (Loi conditionnelle)

Si P(Y = y) > 0, la loi conditionnelle de X sachant Y = y est : P(X = x \mid Y = y) = \frac{P(X = x, Y = y)}{P(Y = y)}

Proposition 3.1 — (Formule des probabilités totales)

P(X = x) = \sum_y P(X = x \mid Y = y) P(Y = y)

Théorème 3.1 — (Formule de Bayes)

P(Y = y \mid X = x) = \frac{P(X = x \mid Y = y) P(Y = y)}{\sum_{y'} P(X = x \mid Y = y') P(Y = y')}

4 Indépendance

Définition 4.1 — (Indépendance)

X et Y sont indépendantes si pour tout (x, y) : P(X = x, Y = y) = P(X = x) P(Y = y)

Proposition 4.1 — (Caractérisation par les lois conditionnelles)

X et Y sont indépendantes si et seulement si la loi conditionnelle de X sachant Y = y est égale à la loi marginale de X, pour tout y avec P(Y = y) > 0.

5 Covariance

Définition 5.1 — (Covariance)

Si X et Y admettent un moment d’ordre 2 : \mathrm{cov}(X, Y) = E((X - E(X))(Y - E(Y))) = E(XY) - E(X)E(Y)

Proposition 5.1 — (Propriétés)

  1. \mathrm{cov}(X, X) = V(X).
  2. \mathrm{cov}(X, Y) = \mathrm{cov}(Y, X).
  3. \mathrm{cov}(aX + b, cY + d) = ac \, \mathrm{cov}(X, Y).
  4. \mathrm{cov}(X + Y, Z) = \mathrm{cov}(X, Z) + \mathrm{cov}(Y, Z).

Proposition 5.2 — (Indépendance implique covariance nulle)

Si X et Y sont indépendantes et admettent un moment d’ordre 2, alors \mathrm{cov}(X, Y) = 0.

La réciproque est fausse : \mathrm{cov}(X, Y) = 0 n’implique pas l’indépendance.

Proposition 5.3 — (Inégalité de Cauchy-Schwarz)

|\mathrm{cov}(X, Y)| \leq \sigma(X) \sigma(Y)

6 Corrélation linéaire

Définition 6.1 — (Coefficient de corrélation)

Si \sigma(X) > 0 et \sigma(Y) > 0 : \rho(X, Y) = \frac{\mathrm{cov}(X, Y)}{\sigma(X) \sigma(Y)}

Proposition 6.1 — (Propriétés)

  1. \rho(X, Y) \in [-1, 1].
  2. \rho(X, Y) = 1 \iff \exists (a, b) \in \mathbb{R}^* \times \mathbb{R} avec a > 0 tel que Y = aX + b presque sûrement.
  3. \rho(X, Y) = -1 \iff idem avec a < 0.

7 Vecteurs aléatoires à densité

Définition 7.1 — (Vecteur aléatoire à densité)

(X, Y) est à densité s’il existe f_{X,Y} : \mathbb{R}^2 \to \mathbb{R}^+ continue par morceaux telle que : P((X, Y) \in D) = \iint_D f_{X,Y}(x, y)\, dx\, dy pour tout domaine D du plan.

Proposition 7.1 — (Lois marginales à densité)

f_X(x) = \int_{-\infty}^{+\infty} f_{X,Y}(x, y)\, dy, \quad f_Y(y) = \int_{-\infty}^{+\infty} f_{X,Y}(x, y)\, dx

8 Exercices

Exercice 8.1

Soit (X, Y) de loi conjointe :

X \setminus Y 0 1
0 0{,}2 0{,}3
1 0{,}1 0{,}4
  1. Déterminer les lois marginales.
  2. X et Y sont-elles indépendantes ?
  3. Calculer E(X), E(Y), \mathrm{cov}(X, Y).

Exercice 8.2

Soient X et Y indépendantes suivant \mathcal{B}(p). Déterminer la loi de X + Y.

Exercice 8.3

Soient X et Y indépendantes suivant \mathcal{E}(\lambda). Déterminer la densité de X + Y.

Exercice 8.4

Soit (X, Y) de densité f_{X,Y}(x, y) = \begin{cases} c(x + y) & 0 \leq x \leq 1, 0 \leq y \leq 1 \\ 0 & \text{sinon} \end{cases}.

  1. Déterminer c.
  2. Déterminer les lois marginales.
  3. X et Y sont-elles indépendantes ?

Exercice 8.5

Soient X et Y avec V(X) = 4, V(Y) = 9, \mathrm{cov}(X, Y) = 3. Calculer \rho(X, Y) et V(X + Y).

Exercice 8.6

Soit X \hookrightarrow \mathcal{B}(n, p). Montrer que V(X) = np(1-p) en écrivant X = X_1 + \cdots + X_n avec les X_i indépendantes suivant \mathcal{B}(p).

Exercice 8.7

Soient X et Y indépendantes suivant \mathcal{N}(0, 1). Déterminer la loi de X + Y.

Exercice 8.8

Soit (X, Y) de densité f_{X,Y}(x, y) = \begin{cases} e^{-y} & 0 \leq x \leq y \\ 0 & \text{sinon} \end{cases}.

  1. Vérifier que f_{X,Y} est une densité.
  2. Déterminer les lois marginales.
  3. X et Y sont-elles indépendantes ?
